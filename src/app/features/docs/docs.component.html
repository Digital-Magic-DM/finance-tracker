TRANSPORT & AUTHENTICATION

2. Protocol Endpoints & Security

The FinTracker MCP server communicates via Server-Sent Events (SSE) and JSON-RPC 2.0 messages over standard HTTPS.

Method Endpoint Auth Required Description
GET / No Health check and service status diagnostic endpoint.
GET /sse Yes Establishes the Server-Sent Events (SSE) streaming transport connection.
POST /message?sessionId=<id> Yes Receives JSON-RPC 2.0 client requests and executes tool calls.

key Authentication Header

When connecting to the remote server, clients provide their personal AI access key generated from Settings > AI & MCP via either:

Authorization: Bearer YOUR_PERSONAL_AI_KEY

Or via URL query parameter for clients that do not support custom EventSource headers:

https://finance-tracker-vczn.onrender.com/sse?token=YOUR_PERSONAL_AI_KEY

account_circle Multi-User & Scoping

The MCP server implements strict multi-tenant isolation. Each personal key is cryptographically bound to that user's Firestore UID. Tool calls automatically operate exclusively on the authenticated user's portfolio with zero cross-user visibility.
